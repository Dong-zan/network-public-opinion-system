## 4. AI 接口

### 4.1 智能问答

接口：

```text
POST /api/ai/ask
```

请求体：

```json
{
  "event_id": 1,
  "question": "这个事件的主要风险点是什么？"
}
```

前端优先读取字段：

- `answer`

前端兼容读取字段：

- `summary`
- `trend`
- `risk`
- `suggestion`

推荐返回示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "answer": "该事件当前主要风险点包括情绪持续发酵、次生谣言传播和官方回应滞后。"
  }
}
```

当前状态：

- 接口可请求成功
- 当前返回仍偏测试内容
- `answer` 目前不稳定，存在占位内容或乱码现象

### 4.2 AI 分析报告生成

接口：

```text
POST /api/ai/report/{event_id}
```

当前前端交互逻辑：

1. 用户在事件详情页点击“生成/刷新AI报告”
2. 前端调用 `/api/ai/report/{event_id}`
3. 调用完成后，前端再刷新一次 `/api/events/{event_id}`

推荐方案 A：接口直接返回完整报告

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "event_id": 1,
    "status": "success",
    "ai_report": {
      "summary": "AI 自动生成事件总结",
      "trend": "AI 对趋势的解释",
      "risk": "AI 对风险的解释",
      "suggestion": "AI 建议",
      "generated_at": "2026-07-12 17:00:00"
    }
  }
}
```

推荐方案 B：接口只负责生成，结果写回事件详情

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "event_id": 1,
    "status": "success"
  }
}
```

然后通过：

```text
GET /api/events/{event_id}
```

读取更新后的：

```json
{
  "ai_report": {
    "summary": "AI 自动生成事件总结",
    "trend": "AI 对趋势的解释",
    "risk": "AI 对风险的解释",
    "suggestion": "AI 建议"
  }
}
```

当前状态：

- 接口可请求成功
- 当前后端仅返回 `status: success`
- 尚未直接返回报告正文
- 也尚未确认是否已将报告内容写回事件详情接口

## 5. 前端当前已做的兼容

前端当前已兼容以下情况：

1. `create_time` 可作为更新时间显示
2. `overview.place` 兼容为 `location`
3. `overview.reason` 兼容为 `cause`
4. `overview.people` 兼容为 `persons`
5. `timeline.title` 兼容为时间线内容
6. `platform_distribution` 中兼容：
   - `name / platform`
   - `value / count`
7. `authenticity_label` / `authenticityLabel` 均可识别
8. `key_nodes` / `keyNodes` 均可识别
9. `ai_report` / `report` 均可识别

说明：

前端已经做了必要字段兼容，但如果后端直接返回空数组、空对象或 `null`，页面对应板块仍然无法展示真实内容。

## 6. 后端需优先补齐的字段

建议后端优先按以下顺序补齐：

### 一级优先

1. `GET /api/events/{event_id}` 中的：
   - `overview.time`
   - `overview.location`
   - `overview.cause`
   - `overview.persons`
   - `trend`
   - `trend_labels`
   - `keywords`

2. `POST /api/ai/ask` 中的：
   - `answer`

3. `POST /api/ai/report/{event_id}` 或 `GET /api/events/{event_id}` 中的：
   - `ai_report.summary`
   - `ai_report.trend`
   - `ai_report.risk`
   - `ai_report.suggestion`

### 二级优先

1. `authenticity`
2. `propagation_analysis`
3. `propagation_path`
4. `trend_highlights`
5. `ai_report.generated_at`

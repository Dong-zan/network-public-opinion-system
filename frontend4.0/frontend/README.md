# 网络舆情事件智能分析系统前端模块

## 1. 模块简介

本模块为“网络舆情事件智能分析系统”的前端部分，负责系统页面展示、用户交互以及与后端接口联调。

前端基于 `React + Vite` 开发，当前已完成课程作业所需的主要页面结构，并预留了与后端、爬虫、NLP 分析、AI 问答模块的对接接口。

---

## 2. 已实现功能

当前前端已完成以下页面与功能：

- 登录页面
- 首页看板
- 舆情事件看板
- 事件详情页
- 智能问答页
- 个人中心页面
- 左侧导航栏折叠/展开
- 当前事件切换
- 热度排序 / 时间排序
- 关键词与关注平台自定义输入
- 前端 mock 数据联调
- 后端接口预留与数据结构适配

## 3. 页面说明

### 3.1 登录页面

实现内容：

- 用户名与密码输入
- 登录按钮
- 登录背景图展示
- 登录状态与错误提示

说明：

当前开发阶段支持 mock 登录，后续可接入后端真实登录接口。

### 3.2 首页看板

实现内容：

- 热点事件总数统计
- 最高热度指数统计
- 高风险事件数量统计
- 热点事件速览列表
- 点击事件后可跳转详情页

### 3.3 舆情事件看板

实现内容：

- 事件标题展示
- 事件摘要展示
- 热度指数展示
- 风险等级展示
- 生命周期展示
- 更新时间展示
- 情感倾向比例展示
- 支持按热度排序
- 支持按时间排序

### 3.4 事件详情页

实现内容：

- 事件完整标题与事件介绍
- 事件概述
- 关键节点时间线
- 发展趋势图
- 情感分布图
- 关键词展示
- 平台分布展示
- 事件溯源与关键传播路径展示
- AI 分析报告展示

### 3.5 智能问答页

实现内容：

- 当前事件切换
- 当前事件信息展示
- 用户输入问题
- 返回 AI 问答结果

说明：

当前支持 mock 问答逻辑，后续可接入大模型问答接口。

### 3.6 个人中心

实现内容：

- 自定义关注关键词
- 自定义关注平台
- 标签新增与删除
- 保存用户配置

## 5. 主要文件说明

- `src/App.jsx`  
  前端主页面逻辑，负责页面切换、登录状态、事件加载、详情加载、智能问答、个人中心等核心交互。

- `src/App.css`  
  页面整体样式文件，包含登录页、侧边栏、顶部栏、看板、详情页、问答页、个人中心等样式。

- `src/main.jsx`  
  项目入口文件，负责挂载 React 应用。

- `src/api/request.js`  
  通用请求封装，统一处理接口请求与返回结果。

- `src/api/event.js`  
  事件列表、事件详情的数据获取与字段适配。

- `src/api/user.js`  
  用户登录、个人中心配置保存接口。

- `src/api/ai.js`  
  智能问答接口。

- `src/data/mock.js`  
  前端开发阶段使用的模拟数据，用于在后端未完成前进行页面开发和演示。

- `public/login-background.png`  
  登录页背景图片资源。

- `index.html`  
  页面入口 HTML 文件，设置网页标题等基础信息。

- `package.json`  
  项目依赖、脚本命令配置文件。

- `vite.config.js`  
  Vite 构建配置文件。

## 7. 安装与运行方式

### 7.1 安装依赖

```bash
pnpm install
```

如果本机没有 `pnpm`，也可以根据实际情况使用 `npm`，但当前项目默认使用 `pnpm`。

### 7.2 启动开发环境

```bash
pnpm run dev
```

启动后可在浏览器访问本地开发地址，例如：

```text
http://localhost:5173/
```

### 7.3 打包构建

```bash
pnpm build
```

## 9. 当前数据模式说明

当前前端支持两种数据模式：

### 9.1 Mock 模式

用于前端独立开发和页面演示。  
在后端尚未联调完成前，前端会优先使用 `src/data/mock.js` 中的模拟数据。

### 9.2 真实接口模式

后续在后端、爬虫、NLP 分析、AI 模块联调完成后，可切换为真实后端接口请求模式。

说明：

- 模拟数据仅用于开发与演示
- 最终系统中的事件标题、时间、来源网站、关键词、平台分布、情感分析、趋势图数据等，均应来自真实后端返回结果

## 10. 与其他成员模块的协作关系

本前端模块与其他成员的协作关系如下：

- `1号成员（项目负责人 + 后端 + 系统整合）`  
  负责提供后端接口，并与前端进行最终联调。

- `3号成员（数据采集与清洗负责人）`  
  负责提供原始新闻数据来源，影响事件时间线、来源网站、事件概述等内容。

- `4号成员（NLP 分析负责人）`  
  负责提供关键词、情感分析、热度、风险等级、生命周期等分析结果。

- `5号成员（AI 功能负责人）`  
  负责提供 AI 问答与 AI 分析报告能力。
